# Moxie UI

[![License](https://img.shields.io/badge/license-MIT%2FApache-blue.svg)](https://github.com/voxell-tech/moxie#license)
[![CI](https://github.com/voxell-tech/moxie/workflows/CI/badge.svg)](https://github.com/voxell-tech/moxie/actions)
[![Discord](https://img.shields.io/discord/442334985471655946.svg?label=&logo=discord&logoColor=ffffff&color=7389D8&labelColor=6A7EC2)](https://discord.gg/Mhnyp6VYEQ)

**Moxie UI** is the reusable `bevy_ui` layer for the
[Moxie](https://github.com/voxell-tech/moxie) editor: widgets, a
dockable panel system, an inspector, and theming, all built as
[`fynix`](https://github.com/voxell-tech/fynix) elements.

## Join the community!

You can join us on the [Voxell discord server](https://discord.gg/Mhnyp6VYEQ).
